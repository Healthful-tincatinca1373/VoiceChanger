## 🛠️ Troubleshooting

**I cannot hear any change in my voice**
Make sure your headphones or speakers are connected and that the correct microphone is selected inside VoiceChanger. Confirm the level meter moves when you speak.

**Other people cannot hear the effect**
Open the audio settings of the program you are using and set VoiceChanger as the input or microphone device. Many programs remember the previous device until you change it manually.

**There is an echo or feedback**
Use headphones instead of speakers. Feedback usually happens when the microphone picks up audio coming out of nearby speakers.

**The application feels slow**
Close programs you are not using. Real-time audio processing works best when your computer is not overloaded.

**Windows blocked the application**
Open the file again and confirm the prompt. If it still does not open, check that the download finished completely and try downloading once more from the link above.
